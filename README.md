# 站牌 100 公尺內有沒有垃圾桶

2026 市政 debug松 題 2「找回消失的垃圾桶」的作品。臺北市 3,407 個公車站牌與 87 個捷運站，各自 50 到 200 公尺內有沒有公共垃圾桶或超商，附問題兩層、要收的三種數字、資料口徑與使用注意。

- 網頁版：`index.html`（單檔，開了就能用，底圖與 Leaflet 走網路）。
- 資料：`data/`，說明見 `data/README.md`。
- 程式：`scripts/`。

## 一句話

臺北市今年把行人清潔箱從 1,682 組撤到 806 組，撤桶的人與要桶的人手上都沒有數字。這個作品先做出第一個可以量的東西：全市 3,407 個公車站牌，一半在 100 公尺內找不到公共桶，也找不到超商（超商資料只覆蓋約六成，這個「一半」是上限）。

## 怎麼操作

打開 `index.html`。切半徑 50／100／200 公尺；選區；勾「只看什麼都沒有的站牌」就是候選名單；點站牌看最近的公共桶、景點桶、超商各在幾公尺外。右側三個分頁：怎麼讀（口徑）、100 天怎麼做、資料與限制。

## 限制

- 距離是直線，不是步行路徑。
- 公園、市場、捷運站內各機關自設的桶不在資料裡。
- 超商門口有沒有桶、收不收路人垃圾，沒有資料集；本作品不假設它收。
- 站牌是 2020 年的檔。
- 本作品不回答「撤桶對不對」。

## 重跑

`index.html` 可以直接重建：`python3 scripts/q2_build_app.py`（讀 `data/data.json`）。

`data/data.json` 要重算需要原始檔（清潔箱兩個 CSV、公車站牌 SHP、TDX 捷運站 JSON、OSM Overpass 回應、村里界 SHP），放在 `CIVIC_DATA` 環境變數指的資料夾，路徑見 `scripts/q2_points.py` 開頭。原始檔沒有放進 repo，來源都在上表，每個都是公開下載。
