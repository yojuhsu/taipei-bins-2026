# data/

- `data.json`：3,407 個公車站牌與 87 個捷運站，各自最近的公共桶（點位表）、景點商圈桶、超商（OSM）距離（公尺），加上 681 公共桶點、130 景點桶、1,566 超商點、87 捷運站的座標。由 `scripts/q2_points.py` 產生。
- `points_summary.json`：50／100／200 公尺的彙總與各區分布。
- `li_table_public.csv`：臺北市 456 里，每里的人口（2026 年 9 月）、樹、人行道長度、清潔箱點、公車站牌、捷運站、人孔、水位站、消防通道、土壤液化抽樣占比等。對外版拿掉了 YouBike、Rat Radar、施工通報三個來源的欄位（授權或個資疑慮）。里界來自內政部國土測繪中心村里界 115/08。

資料授權依各原始來源：政府資料依政府資料開放授權條款第 1 版（要標示來源機關）；超商點來自 OpenStreetMap，ODbL，© OpenStreetMap contributors。

注意：`li_table_public.csv` 的 `acc_a1_2026`、`acc_a2_2026_05` 是警政署逐筆檔的當事人列數，不是事故件數（每件至少兩列，差約 2.3 倍）。留著當參考，不要當件數用。（2026-10-20 更正）
